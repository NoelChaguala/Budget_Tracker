# Fix: Budget model missing category relationship

## Problem
`Budget` model in `app/models.py` has `category_id` foreign key but no relationship to access the `Category` object. This causes `AttributeError: 'Budget' object has no attribute 'category'`.

## Solution
Add a `category` relationship to the Budget model in `app/models.py`:

```python
# In Budget class (around line 154), add:
category = db.relationship("Category", backref="budgets", lazy=True)
```

This allows `budget.category.name` to work correctly.
